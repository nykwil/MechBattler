# Demo video script — target 2:35

## 0:00–0:15 — Hook

**Visual:** Balance Lab hero.

“Game balance usually starts with a hunch and ends with a spreadsheet. MechBattler Balance Lab uses Codex and GPT-5.6 to turn a real deterministic game into an explainable content-tuning workflow.”

## 0:15–0:38 — Run the workflow

**Visual:** Select the 2-seed quick demo and click **Run roster audit**.

“This runs every archetype against every other archetype, from alternating spawn sides, through the exact same simulation as the game. Identical content and seeds always produce the same result.”

## 0:38–1:05 — Read the evidence

**Visual:** Point to headline metrics, standings, and tuning brief.

“The audit applies explicit design guardrails: no build above seventy percent overall, and stock matchups target thirty-five to sixty-five percent. It identifies dominant builds, weak kernels, and hard counters, then recommends the next kind of experiment. The complete evidence can be exported as JSON or run in CI.”

## 1:05–1:35 — Before and after

**Visual:** Show the tuning report table, then return to current standings.

“Our untuned 280-battle baseline found a seventy-six-percent Vulture and a twenty-four-percent Widow. Codex's first experiment overcorrected both, so we rejected it. The accepted content-only pass removed one Vulture armor plate and replaced one Widow machine gun with a routed carbine. That cleared the dominance flag, raised healthy matchups fifty percent, and narrowed roster spread by twelve points.”

## 1:35–2:05 — Prove it is a real game

**Visual:** Switch to Workshop. Show the physical grid, power overlay, brownout priority, and Test Bench. Start a battle or show its report.

“These aren't abstract rows. In the Workshop, every component occupies physical cells. Power requires a connected route, heat conducts between cells, and the player decides what browns out first. The same build can be tested, fought, diagnosed, salvaged, and refitted.”

## 2:05–2:28 — Codex collaboration

**Visual:** Brief repository/test view or README collaboration section.

“I set the product principles and made the key design calls. Codex with GPT-5.6 turned the specifications into the simulation, product, batch harness, diagnostics, and 139-test verification suite. Then we used those tools together for the actual tuning pass—not just to generate code, but to run and reject experiments.”

## 2:28–2:35 — Close

**Visual:** Balance Lab matrix.

“Balance isn't solved by hiding failures. MechBattler makes every remaining failure visible, reproducible, and actionable.”

## Recording checklist

- Keep the final upload under 3:00.
- Record at 1440×900 or 1920×1080 with browser zoom chosen before recording.
- Use voice audio; no copyrighted music.
- Show a live audit completing, not only static screenshots.
- Mention both Codex and GPT-5.6 aloud.
- Make the YouTube video public, not unlisted.
